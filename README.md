# Line Pilot 737

A browser flight simulator: fly airliners between 177 real airports worldwide over real satellite imagery and terrain,
with live weather, regional AI traffic, gate-to-gate operations, 3D flight decks, flight school and an airline career,
plus a Vietnam-era military mode (F-4 Phantom II, F-105 Thunderchief, A-1 Skyraider, UH-1 Huey, AH-1 Cobra) with
tutorials and a 1965–1972 campaign.

Flyable fleet (25 types, with a cockpit for each family): 737-800/900ER, 757 and 767 (incl. UPS freighters),
777-300ER/777F, 787-9, 747-400/747-8F, MD-11F, A320/A321, A330, A350, E175, CRJ-900, ATR 72, Dash 8 Q400,
Gulfstream G650, Citation CJ4, Cessna 172, Pilatus PC-12 and C-130H Hercules.

**Play:** https://dbrokenai.github.io/line-pilot-737/

Runs entirely in the browser (single `index.html`). Needs a desktop browser with WebGL 2 (Chrome, Edge or Firefox).
Press F1 in flight for the controls.
