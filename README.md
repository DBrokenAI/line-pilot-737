# Line Pilot 737

A browser flight simulator: fly a Boeing 737-800 between real US airports over real satellite imagery and terrain,
with live weather, AI traffic, a full 3D flight deck, flight school and a career mode, plus a Vietnam-era military mode
(F-4 Phantom II, F-105 Thunderchief, A-1 Skyraider, UH-1 Huey, AH-1 Cobra) with tutorials and a 1965–1972 campaign.

**Play:** https://dbrokenai.github.io/line-pilot-737/

Runs entirely in the browser (single `index.html`). Needs a desktop browser with WebGL 2 (Chrome, Edge or Firefox).
Press F1 in flight for the controls.
